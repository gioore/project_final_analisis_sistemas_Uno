3. Diagrama de Secuencia — Crear Paciente

            sequenceDiagram
                actor Usuario
                participant Form as PacienteForm.vue
                participant Store as PacienteStore
                participant API as Axios
                participant Ctrl as PacienteController
                participant DB as SQLite

                Usuario->>Form: Completa datos y envía
                Form->>Store: create(payload)
                Store->>API: POST /api/v1/pacientes
                API->>Ctrl: Request con JWT + Tenant
                Ctrl->>Ctrl: Valida datos
                Ctrl->>DB: INSERT INTO pacientes
                DB-->>Ctrl: OK
                Ctrl-->>API: 201 + paciente
                API-->>Store: Response
                Store-->>Form: Resultado
                Form->>Form: Redirige al listado
